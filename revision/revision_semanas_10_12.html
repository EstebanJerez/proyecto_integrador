Convenciones de este informe

Crítico rompe la ejecución o la interfaz. Alto incumple un requisito de la guía o deja pasar datos incorrectos. Medio afecta el contrato o la mantenibilidad. Bajo es una mejora de robustez o de estilo.

En el código, cada cambio lleva el comentario # REVISIÓN, para que puedan buscarlo con Ctrl+F. El trabajo de los estudiantes se conservó: se corrigió y se amplió, no se reescribió desde cero, salvo en lectores.py, donde había que reorganizar las importaciones.

Para aprender: una tabla de equivalencias (diccionario) reemplaza muchos if. Para aceptar una variante nueva basta con agregar una línea. Si la unidad no está en la tabla, se deja tal como llegó y la validación explica el motivo del rechazo. Normalizar no es aceptar cualquier cosa.

4. Rol C — Fuentes de datos

Archivos: src/data/fuentes_memoria.py, src/data/lectores.py, src/data/carga_datos.py · Commit de la revisión: d8d0525

Lo que estaba bien

  • preparar_registros_prueba() es muy completo: formatos diversos, incompletos y tipos no reconocidos, con docstrings y ids propios (serie 1xx) que no alteran los 12 registros base (C-S10-01 a C-S10-03).

C-1Faltaba «import csv»: leer_csv fallaba siempreCríticoS12

leer_csv("data/raw/temperatura.csv") fallaba con NameError: name 'csv' is not defined. Además, los import estaban repartidos a mitad del archivo y quedaban raise NotImplementedError inalcanzables después de cada return.

Para aprender: PEP 8 indica que todas las importaciones van al inicio del archivo, agrupadas (biblioteca estándar, terceros, proyecto). Así un import faltante se nota de inmediato. El código que queda después de un return nunca se ejecuta y solo confunde a quien lo lee.
C-2Los lectores no aceptaban el archivo que entrega Streamlit: CSV y JSON no cargabanCríticoS12

Aceptación S12: «los tres datasets se cargan y procesan con el contrato común». El servicio docente llama a cargar_datos(archivo, archivo.name) con un UploadedFile, que es un objeto parecido a un archivo y no una ruta. open(archivo) fallaba con TypeError.

def _obtener_bytes(archivo):
    if isinstance(archivo, (str, Path)):
        return Path(archivo).read_bytes()
    if isinstance(archivo, bytes):
        return archivo
    if isinstance(archivo, dict):          # forma del estudiante
        return list(archivo.values())[0]
    if hasattr(archivo, "getvalue"):       # Streamlit / BytesIO

        return archivo.read()
    raise ErrorFormatoFuente(...)

7. Cómo estudiar los cambios

  1. Ver todos los cambios de la revisión respecto a lo entregado: 
    git diff be34d3c revision-docente -- src/
  2. Ver solo los cambios de un rol (cada rol tiene sus propios commits): 
    git log --oneline revision-docente
git show d0c476e          # Rol A
git show ea22f58 43e00da  # Rol B
git show d8d0525          # Rol C
  3. Buscar los comentarios # REVISIÓN en cada archivo: explican el porqué de cada cambio en el mismo lugar del código.
  4. Ejecutar la interfaz y cargar los tres archivos de data/raw/: 
    python -m streamlit run src/interface/streamlit_app.py
